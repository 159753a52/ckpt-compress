      --checkpoint <your_checkpoint> \
      --config experiments/configs/pruning_config_block0.json \
      --device cuda

💡 配置说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
你的配置特点:
• attn_proj (75%) 剪枝比例很高 - 测试输出投影的鲁棒性
• mlp_fc/mlp_proj (45%) 中等剪枝 - 平衡压缩和性能
• attn_qkv (25%) 较保守 - QKV 通常更敏感
• ln_2 (10%) 最保守 - MLP 前的 LN 保留更多参数

损失增量判断:
  ≤ 0.001:  ✅ 无损剪枝 - 配置可接受
  ≤ 0.01:   ⚠️ 轻微损失 - 可能可接受
  > 0.01:   ❌ 明显损失 - 需要调整配置

整体稀疏度:
  < 30%:    保守策略
  30-50%:   平衡策略
  > 50%:    激进策略

🎓 使用流程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 运行细粒度分析（可选）
   → 找到每层的最大无损剪枝比例
   $ python experiments/scripts/fine_grained_pruning_analysis.py

2. 设计剪枝配置
   → 基于分析结果或经验设计配置

3. 测试配置
   → 使用本工具验证配置
   $ ./experiments/scripts/test_block0_config.sh

4. 查看结果
   → 检查损失增量和整体稀疏度
   $ cat results/pruning_test_block0/REPORT.md

5. 迭代优化
   → 根据结果调整配置并重新测试

⚠️ 注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 每次运行都会重新计算重要性得分（~5-10 分钟）
2. 使用相同的评估批次确保公平对比
3. 稀疏度建议在 0.0-0.9 之间
4. 高稀疏度（>80%）可能导致性能严重下降

🔍 故障排除
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CUDA OOM:
  → 减小 --batch_size 或 --num_eval_batches

检查点加载失败:
  → 确认检查点包含 model_state_dict

配置文件格式错误:
  → 验证 JSON 格式: python -m json.tool config.json
