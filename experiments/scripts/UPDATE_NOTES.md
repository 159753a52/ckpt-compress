## 🎯 为什么扩展到 90%？

### 优势
1. **更全面的分析**: 可以看到高稀疏度下的性能退化曲线
2. **发现极限**: 找到每层的真正剪枝极限
3. **非线性行为**: 观察高稀疏度下的非线性效应
4. **实用价值**: 某些层可能在 60%-90% 仍然保持无损

### 预期发现
```
可能的模式:
- 0-30%:   大部分层无损或轻微损失
- 30-60%:  开始出现明显差异
- 60-80%:  性能快速退化
- 80-90%:  大部分层严重退化，但某些层可能仍可接受
```

---

## 📈 预期结果示例

### 可能的无损剪枝比例分布

| Layer | 低敏感 Block | 中等 Block | 高敏感 Block |
|-------|-------------|-----------|-------------|
| attn_qkv | 30-35% | 25-30% | 20-25% |
| attn_proj | 40-45% | 35-40% | 30-35% |
| mlp_fc | 60-70% | 55-60% | 50-55% |
| mlp_proj | 70-80% | 60-70% | 55-60% |
| ln_1 | 50-60% | 45-50% | 40-45% |
| ln_2 | 60-70% | 50-60% | 45-50% |

**关键发现**:
- MLP 层可能在 60%-80% 仍然无损
- Attention 层通常在 30%-45% 开始退化
- LayerNorm 介于两者之间

## 🔍 高稀疏度分析的价值

### 1. 发现非线性阈值
```
某些层可能表现出阶跃式退化:
- 0-50%: 几乎无损
- 50-70%: 缓慢退化
- 70%+: 快速崩溃
```

### 2. 识别鲁棒层
```
某些层可能在极高稀疏度下仍然鲁棒:
- MLP Proj: 可能到 75-80% 仍可接受
- 某些中间 Block: 可能更耐剪枝
```

### 3. 设计激进策略
```python
# 基于高稀疏度分析的激进策略
aggressive_pruning = {
    'mlp_proj': 0.75,      # 发现可以到 75%
    'mlp_fc': 0.65,        # 发现可以到 65%
    'ln_2': 0.60,          # 发现可以到 60%
    'attn_proj': 0.40,     # 保守
    'attn_qkv': 0.30,      # 最保守
}
# 预期整体剪枝率: ~55-60%
```
